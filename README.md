# 로비유온 3D 스튜디오 (ROVIYUON 3D Studio)

수납장·선반·문을 다시 그리지 않고 치수로 바로 고치고, 방에 배치해 겹침을 확인한 뒤 부품표·원판 배치·견적 PDF까지 만드는 **Windows용 무료 3D 설계 프로그램**입니다.

- 소개·사용설명: https://roviyuon.com/studio-3d/
- 다운로드: 이 저장소의 [Releases](../../releases) — `ROVIYUON-3D-Studio-*-win64.zip`
- 지원: Windows 10/11 64비트 · 인터넷 연결·회원가입 불필요 · 개인정보 수집 없음

## 설치·실행
1. 압축 파일을 `C:\CAD`처럼 짧은 경로에 풉니다.
2. 풀린 폴더의 `수납장-실행.cmd`를 더블클릭합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다(서명되지 않은 무료 프로그램 안내).
